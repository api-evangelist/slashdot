"Scientists have created a miraculous new way to stop fires from spreading through neighborhoods using nothing but sound," reports the New York Post: Former NASA engineers with California-based Sonic Fire Tech found that using sound waves can snuff out blazes and potentially be used to stop another Pacific Palisades inferno... The technology works by targeting oxygen molecules using low-frequency sound waves that vibrate them, stopping the fire from growing.
