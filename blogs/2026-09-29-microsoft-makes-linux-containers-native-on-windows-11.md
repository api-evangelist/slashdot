BrianFagioli shares a report from NERDS.xyz: Microsoft has made WSL Containers generally available, giving Windows 11 developers a built-in way to build, run, and deploy Linux containers through Windows Subsystem for Linux. The release includes wslc.exe for managing containers, GPU support, networking improvements, health checks, storage mounts, and integration with Microsoft Defender for Endpoint and Intune. Microsoft also claims up to twice the performance when Linux environments access files stored on Windows.
